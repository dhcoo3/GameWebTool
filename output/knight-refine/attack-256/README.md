# 精英骑士 · 256px 八方向持盾斜劈

## 文件
- attack-body-2048.png：人物与地面投影。
- attack-fx-2048.png：独立银白刀光，已处理人物遮挡，正常透明混合叠加。
- attack-combined-2048.png：人物和刀光合成图。
- frames/：上述三层各64张独立256×256 PNG。
- preview.html：自包含PNG动画预览，可切换层、减速、逐帧和显示定位线。
- previews/：八方向单独GIF与八方向汇总GIF；GIF有调色板限制，PNG为交付原图。
- checks/：逐方向8帧检查图。
- timing.json：帧时长与布局；validation.json：像素边界检查记录。
- prompts.json：内置imagegen生成提示词。sources/：新生成的方向参考稿，非旧128像素素材放大。

## 布局
图集2048×2048，每格256×256。第1–8列对应原Idle.png第1–8行方向，列内从上到下依次播放8帧。零起算切片：x=方向索引×256，y=帧索引×256。
地面基准(128,202)，位于单帧局部坐标。帧时长100、100、100、50、50、100、100、100毫秒，总长700毫秒。第8帧恢复第1帧的防御姿势。
四边8像素安全区适用于人物、武器、投影和刀光合成后的全部可见像素。每个方向使用统一缩放比例和两排源稿的公共基线，未逐帧缩放或自动居中。

## 制作说明
角色使用内置imagegen按高分辨率重新生成。刀光由独立像素曲线绘制，根据各方向剑刃位置和投影视角分别计算，遮挡由人物alpha限制。
这是生成式逐帧美术，装备细节仍可能存在局部形变；不同方向的持盾遮挡及挥剑过渡应在实际游戏镜头下复核。未修改原素材或Unity项目。
