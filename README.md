# 生产工厂 · 游戏资产生成

一个在本机运行的游戏资产生成工厂，目前开放地图扩张和场景生成。地图扩张支持边缘补图、自动扩图、地面与物件分层、碰撞/遮挡区域编辑，以及 PNG、PSD、项目和 Unity 2D 资源导出；场景生成可圈选格子区域并生成区域内容。角色和道具生成入口目前处于筹备中。

## 页面

- 生产工厂首页：<http://127.0.0.1:5173/>。介绍游戏资产生成工具，并提供地图扩张、场景生成与筹备中功能入口。
- 地图扩张：<http://127.0.0.1:5173/map-expansion>。可直接访问或刷新此地址；旧路径 `/terrain` 会转至此页面。
- 场景生成：<http://127.0.0.1:5173/scene-generation>。可直接访问或刷新此地址；支持矩形、等距、等距 Z-as-Y 和六边形网格。

## 启动

需要 Node.js 20 或更新版本。首次运行在项目目录安装依赖：

```bash
npm install
npm run dev
```

网页地址：<http://127.0.0.1:5173>。开发服务器和本机 API 服务会一起启动；停止时在终端按 `Ctrl+C`。

## 配置生图服务

在网页右上角打开“服务设置”，填入至少一个服务商的 API key。设置保存在项目目录的 `.local-settings.json`，文件权限设为仅本机用户可读，并已加入 `.gitignore`。服务设置接口只返回 key 是否存在，不返回密钥内容。

- Google 默认模型：`gemini-nano-banana-2.1`
- OpenAI 默认模型：`gpt-image-2.5-sunburst`
- Google 提示词模型：`gemini-3.8-flash`
- OpenAI 提示词模型：`gpt-5.4-mini`
- 千问默认图像模型：`qwen-image-3.0-pro`，提示词模型：`qwen3.8-max`
- 可灵默认图像模型：`kling-v3`

模型 ID 和 API 端点可在设置中编辑。千问用于提示词和场景图像生成；可灵用于地图扩张和场景图像生成，不提供提示词模型。百炼工作空间端点因区域而异，可在千问设置中填写控制台显示的工作空间域名。生图使用对应服务商的 API，用量依服务商规则计费；Codex / ChatGPT 订阅不提供此网页的 API key。

可灵的最终提示词限制为 2500 字符。地图请求会精简系统构图、编辑和比例规则，完整保留用户描述；带参考图时反向词会合入正向提示词并一并计数。仍然超长时，本机在创建远端任务前返回中文提示及需要精简的字数，不会静默截断描述。

若生成提示词或图像时报“API 连接失败”，请先检查本机服务的外网连通性，连接超时不能据此判断密钥或余额。Node 支持环境代理时，`npm run dev` 会使用明确配置的 `HTTP_PROXY` / `HTTPS_PROXY`。macOS 未指定代理环境变量时，会只读检测已启用的系统 HTTPS 代理，将它用于 API 子进程；不修改系统设置，本地网页地址直连。系统只有 SOCKS/PAC 配置时不自动转换，需手动提供 HTTP/HTTPS 代理。显式环境设置及 `NODE_USE_ENV_PROXY=0` 优先，代理设置变化后重启服务。Node.js 22.21+ 或 24.5+ 支持此方式。

Gemini 图像请求使用 Interactions SSE 流式响应及独立连接，兼容服务返回的普通 JSON。流式图像只有收到完成标记后才会接纳；连接断开或响应残缺时不会返回半张图，也不自动重新提交生图。网络错误提示区分超时、传输中断和主动取消，并显示等待时长；若进程已配置代理，会提示检查当前代理线路，而不会一律要求重新设置代理。流式接收不能保证消除代理或服务端的所有断连问题。

只有点击提示词或图像生成按钮时，描述及可选参考图才会发给当前选择的服务商。地图和场景项目保存在本机浏览器；地图拼接导出和场景 Unity 资源 ZIP 均在本机完成。

## 地图扩张工作台

- 初始地图：导入 PNG、JPEG、WebP（最长边保留至 4096 px，保留透明通道），或填写描述生成初始地图；可上传风格参考图，使用 45° 等距视角预设。
- 初始图请求会附加矩形满幅构图要求：等距只限定摄像机视角，地形需覆盖四边及四角，避免生成带背景的菱形展示地块、悬浮底座。网格显示布局不会作为初始图的裁切遮罩；AI 生成结果仍需检查。
- 只有一张主图时，可通过“重新生成主图”沿用当前描述、尺寸、网格和风格参考重新生成；执行前会确认替换，完成后支持撤销。
- 全局规则：右侧“全局规则”页签可填写当前项目的全局正向、反向提示词，统一用于初始生成、主图重生成、手动与自动扩图、局部重绘；分层继续使用专用提示词。默认留空，旧项目描述不变。规则随草稿、项目和可编辑 ZIP 保存，导入新底图时保留。自动任务使用启动时的规则快照；修改规则会清除旧分段与待接纳预览。可灵超长规则会在提交前报错，不截断。
- 八方向扩图：使用上下文参考、分段和自动拼接流程；可选额外上下文，并检查提交给本机服务的参考图和拼接预览。自动选缝可能修改已有图块的重叠区域。
- 单块结果先预览再接纳；支持替换、单块下载和框选局部重绘。替换、接纳、删除、重叠重排和区域编辑均可撤销/重做。
- 地图画布：顶部可设置格子宽高（列数/行数）、Cell 像素宽高，切换矩形、等距、等距 Z-as-Y、六边形及 Point Top / Flat Top 方向，并显示/隐藏网格。默认 32×32 格、Cell 100×100 px；等距 Cell 100×50 px 显示为 2:1 菱形。网格设置随项目和草稿保存，导入底图时也会保留。
- 格内坐标：显示网格时，在每格中心显示半透明白色的（行,列）坐标，与Unity碰撞格导出一致；等距网格从底尖(0,0)向上编号。坐标保持适合阅读的屏幕字号，隐藏网格时同步隐藏，缩得过小时暂不显示以避免重叠。仅作为画布辅助，不写入图片或资源导出。
- 网格对齐：网格外框中心与主图中心对齐，改变行列数、Cell 尺寸或布局类型时保持中心一致。主图左上角为像素坐标 `(0,0)`，X 向右、Y 向下；扩图继续使用此坐标系。Cell 尺寸按真实像素显示，网格较大时会在主图两侧对称延伸。画布标题旁可查看主图中心坐标和网格外框尺寸。
- 画布查看：右键或按住空格拖动，滚轮以鼠标位置缩放；顶部支持放大、缩小、重置 100%、适合画布和切换图块卡片。
- 自动扩图：选中中心图块并设置目标行列（1–9），只补空位。默认顺序生成，每块暂停供检查；接纳后继续，丢弃则停止。已接纳图块成为后续参考；失败后暂停，手动继续/重试。整批可撤销。旧版流程仍支持并发。
- 分层：默认使用“独立重建两张图层”。透明物件层与纯地面层分别从同一原图编辑生成，各按钮一次请求，不再未经确认连续发起两次生图。两套专用提示词可编辑、恢复默认，独立于原场景正反向描述；补地面不再要求重新生成村庄或建筑。
- 直接生成透明物件层支持可灵和 OpenAI。可灵提取物件时单独使用 `kling-v3-omni`，复用现有可灵端点和 API key，通过 `/v1/images/omni-image` 的 `image_list` 传入完整原图，使用 `aspect_ratio=auto`、`result_type=single`、`n=1`；查询也使用 Omni 路径。物件提取不改变设置中的普通地图生成模型。原图只等比缩放，不补边或裁切；参考图宽高至少 300 px、宽高比在 1:2.5～2.5:1、内容不超过 10 MB，超限在提交前提示。账号需具备对应 Omni API 使用权限。
- 可灵通过专用提示词要求真实透明 PNG，不发送未记录的透明背景参数；返回结果会检查 Alpha，未通过时只保留预览供检查和下载，不会自动回退到标准生图、再次计费或把纯色背景当成透明。OpenAI 使用显式的 `background=transparent`、`output_format=png` 参数。工具调用已配置的 API，无法直接调用聊天中的内置 image_gen。纯地面层可使用当前所选服务。
- 物件层保留建筑、树木、围栏、火把、箱桶等立体物件，移除道路、铺地、草地等平面地形；地面提示词反向移除上述物件，并补画其遮住的地面。AI 重建并非逐像素抠图，轮廓、像素细节和对齐仍需人工检查。
- 图层生成后检查物件是否含真实透明和可见区域、地面是否全不透明。失败结果仍保留供预览和下载，但不能接纳，不自动付费重试。两层通过检查后才可接纳；原图保留，接纳可撤销。
- 支持分别导入物件 PNG、地面 PNG。与原图宽高比误差不超过 1% 的完整画幅会映射到当前地图像素坐标，例如 1665×944 映射到 3840×2176；不裁切至物件包围盒。不同画幅会拒绝导入。界面同时展示服务实际尺寸与项目尺寸，图层和提示词随项目 / 可编辑 ZIP 保存。
- 区域：遮挡区、排序调节区、最上层支持矩形、多边形和自由绘制。多边形显示起点，点击起点（屏幕10 px内）、Enter、双击或“保存当前区域”完成；保存后立即加入列表并可直接画下一块，各区域独立保存位置、轮廓、名称和基准Y。矩形与自由绘制松开鼠标自动提交。无效轮廓会保留并提示修改。
- 绘制撤销：多边形绘制中，Backspace、Ctrl/⌘ Z、“撤回上一点”仅撤回当前点；Ctrl/⌘ Shift Z可恢复，新增点清空逐点重做。撤至零点后不会误撤已存区域，保存或Esc取消结束会话；无当前绘制时，顶部与区域面板的撤销/重做操作针对项目历史，整块区域算一次操作。切换类型、形状、页签或选择模式会丢弃未完成轮廓，保留已存区域。输入框保留文本快捷键。
- 区域类型切换时，右侧列表、数量与属性只显示当前类别，清除旧选中项；画布同时保留碰撞、遮挡、排序调节与最上层的可见标记，方便对照绘制。选择与拖动仅操作当前类型，手动隐藏的区域保持隐藏。导出不受影响。
- 区域完成后自动保存草稿；顶部“保存”保存整个项目。选择工具或区域列表可选中并拖动区域。遮挡区分别设置脚底基准Y，排序调节区设置进入后的排序偏移，区域随项目、ZIP、PSD及Unity资源导出。碰撞格仍按原有方式逐格或拖动涂抹。

### 参考用途与最终提示词

初始生成和只有一张主图时的重新生成支持一张参考图：

- **只参考风格（默认）**：使用配色、材质、像素颗粒、造型、明暗和光照，重新设计布局，不继承物件大小、数量和位置。
- **参考布局**：使用道路、建筑群和空地的空间关系；风格来自文字要求，允许按比例库调整位置和尺寸。
- **风格与布局**：兼用视觉风格与空间关系，仍以启用的角色标尺、物件尺寸、道路净宽和占地规则为准。模型可能偏离要求，需要叠加角色检查。

“只参考风格”可在参考图上框选单个矩形样本，或恢复整图。取样只在本机完成，不覆盖上传原图；其他用途使用完整图片，保留取样设置但不应用。角色几何尺寸与像素颗粒分别处理，参考规则不再沿用含糊的 detail scale。

可切换为“文字风格”，直接填写正反向风格要求，或点击“AI提炼文字风格”主动调用一次所选Gemini、OpenAI或千问提示词服务。缺少配置时不会自动切换服务；失败保留旧文字。提炼排除布局、数量、位置和尺寸。仅选择文字模式后生图才不发送参考图片。更换参考图或样本保留文字并提示来源变化，不自动再次收费提炼。设置、提炼来源与模型随草稿、项目及可编辑ZIP保存；旧项目默认仅风格图片参考。导入新底图保留参考设置。

右侧“提示词”页签可预览初始图、主图重生成、手动扩图各分段、局部重绘、整图蒙版、蒙版修补地面及独立分层的最终正反向内容。预览与实际服务调用共用组装逻辑，包含系统、全局、比例与服务规则，支持复制，并显示模型、请求画幅、参考用途、图片/遮罩状态和字符限制。预览只访问本机 `/api/map/preview`，不调用上游AI，不要求配置API key；风格提炼使用独立的 `/api/map/style`。

仅保留最近一次生图任务的完整请求记录，包含实际诊断、状态、分段和失败原因。新任务首次提交后替换旧任务，自动任务暂停重开后继续追加；随项目和ZIP保存，不保存API key或图片Base64。网络中断时提交状态可能未知，不自动重试；可灵超长规则可预览但在生成前拦截，不截断、不自动关类别。扩图与重绘继续参考已有地图位置，分层继续使用专用提示词，不受初始参考用途影响。

### 角色比例与试走

打开“比例”页，展开“角色预览与试走”，点击“载入临时角色图片”。内置暗红兜帽冒险者由已配置的可灵服务以 1K、单张生成，绿色背景在本机按边缘连通区域去除；原图、透明原尺寸版本、96 px 版本和参数保存在 `public/assets/scale-reference/`。载入或恢复方案仅复用本地素材，不会再次调用 API。也可替换透明 PNG，透明边距不计入可见高度。

新地图默认启用 44×28 px 角色标尺与完整物件库，脚底碰撞为 16×8 px，移动速度为 160 地图像素/秒；无需角色图片即可生成。旧项目保留原尺寸与开关，旧门洞、成熟树参数迁移为库中对应范围，其余新类别关闭。新规范不会修改已有地图、网格或 PPU。

“比例”页按地面点缀、道具与障碍、植物、建筑与入口分组，提供 11 类内置物件的可见高度、可选宽度范围，并支持添加、命名、关闭和删除自定义类别。树木宽度指树冠，门洞宽度指净宽。勾选仅约束实际出现物件，不要求模型画出所有类别。草石 2–9、箱桶 11–20、围栏 18–27、灌木 14–27、岩石 18–45、小树 45–62、成熟树 72–107、门洞 52–60、小屋 81–126、民居 107–162、大厅商店 126–215 px。

“应用44像素规范”重置角色可见尺寸及内置物件范围，保留自定义、图片、碰撞和移动参数，可撤销。修改角色高度不自动改库；“按当前角色高度等比调整物件库”按上次标尺高度同比调整全部物件范围与道路像素净宽，更新标尺后重复点击不会重复缩放，占地格数不变。道路净宽和小屋地面占地与建筑可见高度、碰撞范围分别设计。

尺寸库随项目、草稿、比例参数 JSON、可编辑 ZIP 和自动任务快照保存；导入新底图保留设置。临时角色图片载入或替换均保留当前尺寸，不恢复96像素旧方案。仅启用类别进入请求；有效规则变化清除旧分段和预览，关闭类别的数值编辑不影响缓存。可灵规则超长时在提交前报错，不截断、不自动关类别。
1. 拖动角色到房门、道路旁，用“以 100% 聚焦角色”对比比例，修改参数。
2. 需要时重新生成地图。启用后初始图、扩图、局部重绘只发送数值尺寸规则，不上传角色图片；按本次裁剪、补边和分段范围换算为输出画面百分比。分层物件与地面重建不附加物件比例。AI 对比例的遵守程度仍需用角色叠加检查。
3. 在“区域”页标记碰撞区，再回到“比例”页点击“开始试走”。WASD / 方向键移动、斜向速度归一，Esc、文本输入、失焦、切换工具停止；只允许脚底位于已接纳图块覆盖范围内。碰撞检测为脚底椭圆对多边形，并通过运动小步进避免穿墙；隐藏轮廓仍生效。没有碰撞区域时，仅检查移动和比例。
4. 比例与角色位置随项目、草稿和可编辑项目 ZIP 保存。修改生成尺寸规则会清除旧分段与待接纳预览、结束旧队列快照；拖动和隐藏角色不影响生成。导入新底图保留启用的方案，重新摆放角色。

首版角色为单帧站姿覆盖显示，不处理动画、动态遮挡，不增加 Unity 角色控制器。正式 PNG、PSD、分层 ZIP、Unity 地图包均不烘焙测试角色；只有可编辑项目 ZIP 包含角色素材与配置。

### 项目与导出

项目素材以 Blob 存入浏览器 IndexedDB，项目记录保存素材引用，草稿自动保存。正在运行的任务重新打开后保持暂停，用户继续后才发送请求。旧地图按原坐标、0% 重叠打开，首次保存为新版副本，原记录保留。

导出包括合成 PNG、分层/分块 PNG ZIP、分层 PSD、完整可编辑项目 ZIP，以及 Unity 2D ZIP。PNG / PSD 合成超过安全尺寸时应使用分块 ZIP。PSD 为 RGB 8-bit 图层，保留透明物件和独立遮挡区域。没有已接纳的纯地面层时，Unity包、分层PNG和PSD均保留完整原图铺底，不因提取遮挡区或最上层区域挖空底图；有地面层时使用地面铺底。此兜底适用于静态地图遮挡，隐藏或移动独立物件后，原图中仍保留该物件。修复前导出的包需要重新导出并导入。完整项目 ZIP 可通过“打开”或“导出”面板重新导入。

Unity ZIP 的 `map.json` 使用左上原点、Y 向下的地图像素，默认 100 Pixels Per Unit。包内附 `Unity/Runtime`、`Unity/Editor` 和使用说明；将整套 Unity 文件夹放到工程 `Assets/Unity`，保留 `Assets/Unity/Runtime` 和 `Assets/Unity/Editor` 两个子目录。不要放在 `Assets/Editor/Unity`：运行时组件不能位于任何 Editor 目录或仅编辑器使用的程序集下。若已放错，应移动原文件而不是复制第二份，等待重新编译后再导入。导入器会提前检查运行时程序集并提示目录问题。通过 **Tools → 生产工厂 → 导入 2D 地图** 选择 `map.json`，在 `Assets/GeneratedMaps` 生成或更新同名 Prefab。导入器使用 SpriteRenderer、PolygonCollider2D，地面和最上层固定排序，标记遮挡区独立裁成 Sprite。角色可添加 `FactoryMapSort`、启用 Follow Transform 并指定地图 Root 和 Feet，使用相同脚底 Y 排序及调节区域。

图像模型的分层和道路衔接需要人工检查；碰撞与排序区域由用户绘制。左侧“服务输出尺寸”按当前模型显示支持的档位：Gemini Nano Banana 2.1 / Pro 提供原生、1K、2K、4K；3.1 Flash Image 额外提供 512（0.5K）；Lite 提供原生、1K；未知模型仅使用服务原生尺寸。通用档位用于初始生成、扩图、重绘及物件/蒙版生成；Gemini 的 2K/4K 请求不再把参考图缩至 1536 px。OpenAI 使用原生尺寸；千问和可灵提供原生/1K/2K。地图工作尺寸与服务实际输出尺寸分别显示，不承诺放大等同于更高的原生细节。

Gemini **地面层**使用独立的“地面层输出质量”设置，默认自动匹配原图；支持的模型可手动选择 1K、2K、4K。自动档位按模型实际画幅尺寸选择，3840×2176 地图使用 4K。Lite 模型只提供已确认支持的档位；未知或旧模型的自动选项使用服务默认，不猜测高分辨率能力。高档位通常增加费用和等待时间。

地面生成维持一次整图请求，不额外生成蒙版、不分段、不自动重试或降档。发送给 Gemini 的地面参考图保留导入像素，仅为宽高比增加留边，不经过 1536 px 缩小；超过 36 MB 请求限制时明确报错。默认提示词要求保留地面纹理和局部对比度，自定义提示词继续独立于地图描述。

面板显示原图、发送、实际返回和对齐尺寸，以及实际模型、请求与解析后的档位；尺寸不足会标明放大。下载可选择服务原始结果（保持服务响应的 JPEG/PNG 字节）或对齐地图版本（PNG），转存 PNG 不会增加细节。质量设置、两份素材和生成信息均保存在项目 ZIP；旧项目默认使用自动档位，已有图层不重生成。整图重建仍可能改写纹理，清晰度修正不保证模型逐像素还原。

Gemini 物件层会本地清理洋红底，包括不与边界相连的封闭空隙、暗紫色残留和 JPEG 混色边缘；与原图匹配的紫色物件细节受到保护。“本地清理紫底 · 无需生图”可以处理已有预览或已接纳物件，保留清理前素材并支持撤销及项目 ZIP 往返，不调用图像服务。旧 Gemini 图层需要完成紫底检查后再接纳；检查通过仍需人工查看轮廓。清理预览不自动接纳，也不会修改地面层。

## 开发验收

```bash
npm test
npm run build
```

建议另启独立端口 `npx vite --host 127.0.0.1 --port 5174 --strictPort`，打开 <http://127.0.0.1:5174/tests/browser.html>，点击“运行本地验收”。此页面用模拟服务验证像素保护、分段恢复、独立分层、导出往返、队列暂停/停止/重试、角色素材往返和四服务比例传递。独立端口与正常工作台的项目存储隔离；测试不使用真实 API key。不要在存有正式项目草稿的来源运行验收。

页面另有“下载 UI 验收样例项目”与“准备比例试走样例”，可检查画布、64×120 px 门洞、96 px 道路和 24/64 px 通道。验收页只供 Vite 开发环境使用，不包含在生产构建中。

## 场景生成

1. 在首页打开“场景生成”，可调整画布宽高、Cell 像素宽高与网格布局；初始画布为 32 × 32，Cell 为 100 × 100 像素。
2. 使用画笔或矩形框选格子，再点击“将选区创建为区域”。区域可设置名称和 0–9 层级；同一层的区域不能重叠。
3. 在右侧填写区域描述、正向提示词和反向提示词，可选上传参考图或使用其他区域的生成图。选择 Gemini 或 OpenAI 后，可先生成提示词，再生成区域图像；图像会按所选格子形状裁切显示。
4. 选择“标记碰撞”或“擦除碰撞”工具可逐格编辑碰撞标记。保存项目后可从“打开项目”继续编辑；导出 Unity ZIP 会生成每层一张透明 PNG 和包含网格、区域与碰撞数据的 `scene.json`。
5. 旧版场景项目打开时会自动迁移：已放置素材转换为区域，完整旧项目数据会保留在迁移备份中。

### 扩图衔接与接缝修复

- 地图扩展恢复使用原有参考方式、分段、校色和选缝，新任务默认采用旧版流程。已接纳图块和服务原图保留；曾使用简化流程的未完成任务会停止并保留数据，已有待检查预览仍可接纳或丢弃。旧版暂停任务可继续。
- “生成 → 跨图块接缝修复”：框选接缝两侧，生成预览后可对照前后结果、200% 放大检查，再接纳或丢弃。每次修复只请求一次，按生成结果尚未还原的外围上下文自动校正曝光和色偏，选区外像素受本机保护。预览中的“本地校正颜色”可复用已保存的服务原图重新校正，不调用 AI；样本不足或上下文变化过大时不强制匹配。多图块修改一次撤销/重做。
- 接纳后旧分层与原图引用保留在项目备份中，受影响图块需要重新分层；请复查该范围的碰撞与遮挡标记。项目 ZIP 保存这些备份，PNG、PSD 和 Unity 导出使用接纳后的图块。不会自动发起付费修复或重试。
- 独立来源打开 `/tests/browser.html?seams` 可运行模拟接缝专项验收；不应在正在编辑正式项目的同一浏览器来源运行测试。

### 整块扩图拼接

- 扩图保留原始服务图和候选图。重叠区外侧一半作为生成锚定区，靠近新区域的一半允许生成与本地选缝。整块新区域按对应锚定像素校正曝光与 RGB 色偏；不足或不一致时不强制调整。
- 最小代价路径使用颜色差、梯度差和高对比轮廓惩罚。选缝过渡默认 8 地图像素，可设 0–32；高对比位置取消过渡。最终接缝按世界坐标写回所有受影响图块，旧锚定区保持原样。
- “生成 → 拼接后处理”可对照原始结果和处理后、显示路径、查看颜色和结构诊断、有效像素尺寸，并重新计算本地处理。已有图块可“重新处理已有拼接（本地）”，不发送 AI 请求。缺失服务原图和裁切信息的旧图明确降级；不伪造丢失的重叠。
- 自动任务遇到低置信度、明显结构差异、无法选缝或有效输出不足时暂停，保留待检查预览及原始候选。人工接纳后继续；不自动付费重试。审核预览、诊断、算法版本、处理参数及备份随草稿、项目 ZIP 保存。
- 相交旧分层备份并提示重做；碰撞和遮挡标记保留。建议先扩图、接缝验收，再做分层。PNG、PSD、分块和 Unity 导出均使用已接纳图块。
- `/tests/browser.html?stitch` 为整块拼接专项模拟验收。真实样例和未修复的视觉限制见 `output/map-stitch-review/README.md`。

扩图的物件比例以干净参考图中同类物件的像素尺度和镜头缩放为最高约束；44 px 角色或物件库范围仅作辅助，冲突时不要求模型把新区域改成另一套大小。此规则只影响后续扩图请求，不会自动缩放已生成地图；初始图仍按已启用的数值比例生成。

扩图使用上下文参考；是否发送独立的额外上下文图取决于所选服务及其支持情况。模型仍可能造成物件或道路错位，需检查预览；显式使用跨图块修复会修改选区内原图像素。

旧项目的扩图描述会保留，原先未启用的描述可在生成面板中恢复；旧手动任务的未完成分段和旧单模板自动任务的未完成分段保留为备份，继续扩图时重新生成，已完成图块与待检查预览保留。
